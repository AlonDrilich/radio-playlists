Internet radio M3U playlists by country and genre

Free M3U playlists of internet radio stations, one per country and one per genre, rebuilt every week from Radio Browser, a community-maintained directory whose data is released to the public domain. Only stations that passed the directory's most recent stream check are included, at most 300 per playlist, sorted by community votes.

72FM does not own, operate or curate these streams. They are the directory's entries, filtered automatically. Streams go offline or move between checks, so some entries will not play.

Listen in the browser on 72FM → 72fm.com

  • 48,666 working, de-duplicated stations in the directory at the last build
  • 166 country playlists, 60 genre playlists, and a top 500 by votes playlist
  • Last updated 2026-09-28
  • Every playlist with its raw URL, for scripts: index.json · source code: GitHub

How to use

VLC: Media → Open Network Stream, paste a playlist link (the “Download .m3u” links below), or download the file and open it.

mpv: use > and < to move to the next or previous station.

mpv https://raw.githubusercontent.com/AlonDrilich/radio-playlists/main/countries/de.m3u

Command line download:

curl -LO https://raw.githubusercontent.com/AlonDrilich/radio-playlists/main/genres/jazz.m3u

More player notes (pyradio, Home Assistant, ESP32 and Raspberry Pi) are in the README.
