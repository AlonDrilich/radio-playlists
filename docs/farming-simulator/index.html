Farming Simulator 25 and 22 radio stations by country

Farming Simulator 25 plays internet radio from a list in streamingInternetRadios.xml. Below is a ready-made file for each of 154 countries, with up to 100 of its most-voted MP3 stations, from the public-domain Radio Browser directory, rebuilt every week. It works for Farming Simulator 22 too.

How to install: Close the game and put the file in Documents/My Games/FarmingSimulator2025/music (FarmingSimulator2022 for Farming Simulator 22), keeping a copy of the file already there. The name has to stay streamingInternetRadios.xml.

Pick your own stations on 72FM →

Streams belong to their stations and go offline or move from time to time, so a few entries may not play. 72FM is not connected with the games' makers.
