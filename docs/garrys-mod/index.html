Garry's Mod radio stations by country — 3D Stream Radio playlists

On a multiplayer server, Garry's Mod's 3D Stream Radio plays only addresses found in the server's playlist files. Below is a ready-made playlist for each of 163 countries, with up to 100 of its most-voted stations in formats the radio lists (MP3, OGG, AAC, FLAC), from the public-domain Radio Browser directory, rebuilt every week.

How to install: Put the file in garrysmod/data/streamradio/playlists on your server, keeping the _pls.txt ending, then run sv_streamradio_url_whitelist_reload (or restart the server). The stations then appear in the radio's playlist browser.

Pick your own stations on 72FM →

Streams belong to their stations and go offline or move from time to time, so a few entries may not play. 72FM is not connected with the games' makers.
